[h1]AI Improve – Development Version[/h1]
[b]This is the testing build of AI Improve.[/b] It is updated automatically with every change, before the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3782858610]Release Version[/url]. It may be unstable. For normal play, use the Release Version.

[b]Never subscribe to both versions.[/b] They are the same mod and will conflict.

[h2]Developer tools are included[/h2]
This build contains testing tools that the Release Version does not:
[list]
[*]A developer panel triggered with Ctrl+Shift+R and Ctrl+Shift+T, used to force rare events such as thunderstorm handling and level reloads.
[*]Experimental probes that can [b]deliberately alter vehicle paths[/b] to test new behaviour.
[*]The path-altering LateMergeProbe is disabled unless explicitly enabled at build time.
[*]If a custom build enables it, restart the game to stop it; disabling the mod during the session does not remove its patch.
[/list]
Only use this version on a copy of your save, and only if you know why you need it.
