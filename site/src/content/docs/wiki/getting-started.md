## 1. Subscribe to the dependencies

- **[Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402)** — required by AI Improve. It is a shared library that many Cities: Skylines mods use to change game behaviour safely.
- **UnifiedUI** — optional for AI Improve. With it installed, AI Improve adds a button to the UnifiedUI toolbar so you can change settings without leaving your city.

Automated Public Transport Planning and AI Gaming need no other mods.

## 2. Choose Release or Development

Every mod has two Workshop items:

| | Release Version | Development Version |
| --- | --- | --- |
| For | Everyday play | Trying changes early and helping test |
| Updates | When a version is ready | Automatically with every change |
| Testing tools | Not included | Included (see each mod's page) |

**Subscribe to only one of the two.** They are the same mod and will conflict if both are enabled. Links are on each mod's page: [AI Improve](/Cities_Skylines_1_Modpack/ai-improve/), [Automated Public Transport Planning](/Cities_Skylines_1_Modpack/automated-public-transport-planning/), [AI Gaming](/Cities_Skylines_1_Modpack/ai-gaming/). Items that are not public yet are marked “not yet public”.

## 3. Enable and configure

1. Start the game and open **Content Manager → Mods**.
2. Enable the mod (and Harmony, for AI Improve).
3. Open the mod's options from the **Options** menu to adjust it. For AI Improve, the [settings guide](/Cities_Skylines_1_Modpack/wiki/ai-improve/settings/) explains every switch.

## 4. If something goes wrong

Open an issue with the [issue forms](https://github.com/SpaceSquare640/Cities_Skylines_1_Modpack/issues/new/choose). Include the mod and version, your other mods, the steps that lead to the problem and the relevant part of the game's output log. The [FAQ](/Cities_Skylines_1_Modpack/wiki/ai-improve/faq/) explains where to find the log. Remove your Windows username or other private details before posting.
