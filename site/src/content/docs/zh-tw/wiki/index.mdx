## 模組

| 模組 | 狀態 | 目前能做什麼 |
| --- | --- | --- |
| [AI Improve](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/overview/) | 已在 Workshop 發布 | 讓車輛、公共服務與市民依壅塞、閒置運能與附近需求做反應。共 25 項可開關功能。 |
| [Automated Public Transport Planning](/Cities_Skylines_1_Modpack/zh-tw/wiki/transport/overview/) | Development prototype · game acceptance pending | Previews proposals and can attempt confirmed route creation; it may change saves. |
| [AI Gaming](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-gaming/overview/) | Development preview · runtime unverified | A matching Windows x64 Companion is available for player-confirmed Ollama Local advice. |

每個模組都能單獨使用，一起安裝時也不會互相衝突。
