公共運輸自動規劃會依城市的真實需求規劃公車路線。每條提議的路線都會先預覽，你確認之前什麼都不會建立。**0.2.0** 是打基礎的早期預覽版。

## 0.2.0 能做什麼

- **載入城市時進行調查。**在背景讀取道路、站點與大眾運輸網絡。這是唯讀的：城市與存檔中不會有任何東西被建立、修改或移除。
- **模組選項中的診斷工具。**每個按鈕都會把結果寫入遊戲記錄：

| 按鈕 | 回報內容 |
| --- | --- |
| 將測試路線寫入記錄檔 | 確認模組已載入並正常回應。 |
| 列出公車 prefab 詳細資料 | 你的遊戲中可用的公車車型。 |
| 量測規劃成本（會短暫停頓） | 在你的城市上進行規劃需要多少時間。 |
| 擷取世界快照 | 規劃器會用到的道路與站點。 |
| 建立路線圖 | 各站點之間可能的連接網絡。 |

- **語言選擇。**11 種語言，可在模組選項中切換，不需重新啟動。

## 目前還不能做什麼

它不會建立、修改或建議公車路線。自動規劃仍在開發中，見[路線圖](/Cities_Skylines_1_Modpack/zh-tw/wiki/project/roadmap/)。

## Development 版

Development 版另外包含一個存檔往返測試，會**在目前載入的城市中建立和移除測試公車路線**。它的按鈕要先勾選確認框才能使用，而且每次打開選項頁都會重新變回未勾選。請只在存檔副本上使用。

## 協助測試

在不同規模的城市上執行診斷工具，並在[回報結果或問題](https://github.com/SpaceSquare640/Cities_Skylines_1_Modpack/issues/new/choose)時附上記錄內容。這能幫助規劃器在推出前調整得更好。
