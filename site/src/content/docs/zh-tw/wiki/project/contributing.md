## 回報問題或提出建議

請使用 [Issue 表單](https://github.com/SpaceSquare640/Cities_Skylines_1_Modpack/issues/new/choose)。表單分為錯誤與相容性回報、功能建議，以及 Workshop 更新請求。錯誤回報該附上哪些資料，請見[常見問題](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/faq/)。

請不要在 Issue 中張貼 Steam 密碼、Steam Guard 驗證碼、API key 或其他私人資料。

## 測試 Development 版

每個模組在 Workshop 上都有 Development 版，會比 Release 版更早收到修改。在存檔副本上試用並回報你發現的狀況，是最有幫助的參與方式之一。
