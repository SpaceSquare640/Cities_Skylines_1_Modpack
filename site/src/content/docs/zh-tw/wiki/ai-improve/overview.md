AI Improve 讓城市裡的車輛、公共服務與市民有更好的判斷。原版遊戲很多決定都不看當下狀況：前方塞住了車子照原路走；火車擠在同一個月台，旁邊卻空著；一場小火派出好幾台消防車。AI Improve 一次改善一種行為，而且每一種都有獨立開關。

## 改善了什麼

| 領域 | 簡介 |
| --- | --- |
| 道路交通 | 私家車、計程車、貨車、市內與城際公車，前方壅塞時會重新考慮路線。 |
| 鐵路 | 地鐵與城際列車選擇空閒月台，並可繞開壅塞。 |
| 航空與航運 | 機場登機口、客運直升機起降點與港口碼頭依實際使用情況分配；雷暴時機場拒絕起降。 |
| 緊急服務 | 同一棟建築的消防出勤數有上限；閒置消防車先處理附近火警；雷暴時緊急直升機停飛。 |
| 環衛 | 還有空間的垃圾車與靈車，會先處理附近的建築。 |
| 市民 | 較少開車前往已壅塞的目的地，並更常搭計程車。 |
| 選用功能 | 緊急車輛改道、沒人候車時縮短停站、拉開同線車輛間距。預設關閉。 |

每項功能的說明、預設值與可調數值，請見[全部功能](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/features/)。

## 需求

- 必須使用 **[Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2040656402)**。
- **UnifiedUI** 為選用，可提供遊戲內面板，見[遊戲內使用](/Cities_Skylines_1_Modpack/zh-tw/wiki/ai-improve/in-game/)。
- Enable only one copy of AI Improve, whether it comes from Steam Workshop or a manually installed GitHub Development build.

## 語言

English、繁體中文、简体中文、日本語、한국어、Deutsch、Français、Español、Русский。預設跟隨遊戲語言，也可以在模組選項中另外指定。

## 已知限制

飛機滑行時的改道目前不會觸發：實際量到的滑行道壅塞程度，從未達到它的反應門檻。開關存在，但暫時不會有效果。
