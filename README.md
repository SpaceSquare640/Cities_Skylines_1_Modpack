# Wireless Utilities and Global Coverage

Planned module for Cities: Skylines 1 in the Cities Skylines 1 Modpack.

## Status

This branch contains project documentation and a cloud scaffold check only.
There is no game implementation, compiled DLL, installable package, or validated gameplay behavior yet.

The intended scope is city-wide electricity, water, sewage, and heating coverage without manually placed utility connections. Actual behavior, compatibility, and save handling require a separate approved design and implementation.

## Cloud checks and future delivery

The `Wireless Utilities scaffold checks` workflow runs on GitHub-hosted Ubuntu for pushes and pull requests targeting `Wireless_Utilities_And_Global_Coverage`. It can also be requested manually on that branch. It verifies required documentation, whitespace, and the official license file's SHA-256 digest. It does not compile or test a game mod.

Future builds require an approved source of the game's reference assemblies and an implemented project. Their source remains unresolved. No automatic release or Workshop upload is configured here. When implemented, this module is intended to publish its DLL and necessary files directly as its own GitHub Release assets, without ZIP packaging. Gameplay acceptance must use the Steam Workshop subscribed build.
