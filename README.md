# Automated Public Transport Vehicle Management

Planned Cities: Skylines 1 module for adjusting public transport vehicle allocation to route demand. No gameplay implementation, project file, DLL, or playable build exists yet.

## Automation

The branch-specific GitHub Actions workflow checks required documentation and license integrity on GitHub-hosted Ubuntu. It does not build or validate a mod. No self-hosted runner or automatic release is configured.

Future builds require a real implementation, a compatible compiler, and a legally supplied set of Cities: Skylines and Unity reference assemblies. Their cloud provisioning remains unresolved. Future module releases should attach the DLL and necessary files directly to GitHub Releases, without ZIP packaging. Publishing remains disabled until those prerequisites and meaningful checks exist. Stable Workshop upload is a separate authorized local operation.
