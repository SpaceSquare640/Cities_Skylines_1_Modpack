# Realistic Vehicle Traffic Control

Planning-stage component of Cities Skylines 1 Modpack. The intended scope is vehicle traffic rules, signals, turning restrictions and lane allocation. No game behavior is implemented yet.

## Development status

This branch contains documentation and a cloud repository baseline check only. There is no project file, game DLL, installer, or validated gameplay feature.

A future build needs an agreed framework/toolchain, a reviewed source of licensed Cities: Skylines game reference assemblies (including ICities and Unity dependencies as required), and implementation and tests. These dependencies are not provisioned by this baseline.

## Automation and distribution

The branch baseline runs on pushes and pull requests targeting this branch, and manually. It checks repository text and licensing on GitHub-hosted Ubuntu. It does not build or publish a mod.

Future cloud builds will attach this module's DLL and necessary files directly to its own GitHub Release, without ZIP archives. Release publication remains disabled until dependencies and validation are ready. Steam Workshop stable uploads remain a separate, explicitly authorized local operation.
